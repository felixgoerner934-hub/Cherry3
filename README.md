# SpawnerBeacon 1.2.0 (Fabric, Minecraft 26.1.2)

Client-Mod: Lichtstrahl ueber Spawnern, sichtbar durch Bloecke.
Menue mit der Ue-Taste (Kirschbaum-Design, Farbwaehler pro Spawner-Art).
Kirschblueten-Design: Titelbildschirm, Menue- und Ladehintergruende (Panorama) sowie Buttons und Slider.
Die Bilder liegen in src/main/resources/assets/minecraft/textures/gui/.
Bauen: `gradle build` (Java 25), Ergebnis liegt in build/libs/.
